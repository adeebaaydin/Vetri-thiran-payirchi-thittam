# PocketSmart AI

PocketSmart AI is a complete FastAPI + Jinja2 web application for
budget-aware AI recommendations.

## Features

- Home Interior Planner
- Party Planner
- Jewelry Planner
- Optional outfit image upload
- Gemini AI integration
- Fallback recommendations
- User registration
- Login/logout
- Session management
- Recommendation history
- SQLite database
- Responsive frontend
- FastAPI API
- Interactive API documentation
